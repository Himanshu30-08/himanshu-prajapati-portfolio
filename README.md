# Himanshu Prajapati Portfolio

## Run locally
1. Extract this ZIP.
2. Keep `index.html`, `himanshu.jpg`, and `resume.pdf` in the same folder.
3. Double-click `index.html` to open it in a browser.

The page uses a relative image path (`./himanshu.jpg`), an animated floating portrait, an animated outline halo, moving marquee text, and scroll reveal effects. No npm install or build step is required.

## Deploy
Upload all files in this folder to a GitHub repository, then import the repository into Vercel as a static site.
